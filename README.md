# EnergiaAI Kontroll

Vállalati MI-rendszerek AI Act-alapú besorolását, követelménykezelését és megfelelőségi dokumentációját támogató alkalmazás.

## Fejlesztés

```bash
npm install
npm run dev
```

Az alkalmazás ezután a `http://localhost:3000` címen érhető el.
